# Java

Repositório contendo projetos desenvolvidos em Java com foco em prática, aprendizado e desenvolvimento de aplicações.
Os projetos abordam diferentes conceitos da linguagem Java, incluindo Programação Orientada a Objetos (POO), interfaces gráficas, manipulação de eventos, consumo de APIs, requisições HTTP e tratamento de dados.
## Tecnologias utilizadas

- Java
- JavaFX
- Maven
- JSON (org.json)
- HTTP Client API

## Projetos disponíveis

- Calculadora de IMC
- Relógio Digital
- Gerador de Senhas
- Sistema Climático

## Objetivo do repositório

Este repositório foi criado com o objetivo de documentar minha evolução nos estudos de Java, reunindo projetos práticos para reforçar conhecimentos em desenvolvimento desktop, lógica de programação e integração com serviços externos.
